# ЛР 4 · CineMatch — Data Card v1

**Версия:** 1.0 · **Дата:** 08.11.2026 · **Подготовка:** документирование входных источников до реализации ML-пайплайна.  
**Реестр:** [sources.md](sources.md) · **Схема:** [schema.md](schema.md) · **План и split:** [split_and_plan.md](split_and_plan.md)

## 1. Мотивация и назначение

CineMatch — учебный прототип рекомендательной системы фильмов для креативной индустрии (кино и цифровые медиасервисы). По истории оценок и жанрам система выдаёт персональный Top-10 и сравнивает content-based ранжирование с популярностным baseline. На этапе ЛР 4 документируется пригодность, происхождение и допустимость данных; модель и продуктовые метрики здесь не заявляются как уже обученные/измеренные.

**Допустимое применение:** обучение и воспроизводимые некоммерческие эксперименты с фильмами и рекомендациями. **Недопустимые без дополнительной проверки сценарии:** коммерческая эксплуатация, импорт постеров и описаний с внешних площадок, выводы о предпочтениях реальной современной аудитории и утверждения о фактическом росте CTR.

## 2. Происхождение и состав

**Основной набор:** GroupLens MovieLens `ml-latest-small`, срез с датой генерации 26.09.2018; оценки с 29.03.1996 по 24.09.2018. Первичная информация: [официальный README](https://files.grouplens.org/datasets/movielens/ml-latest-small-README.html). Отмеченные в источнике объёмы:

| Часть набора | Raw по README | Clean v1 | Использование |
|---|---:|---|---|
| `movies.csv` | 9 742 фильма | ещё не рассчитано | названия, жанры и кандидаты |
| `ratings.csv` | 100 836 оценок; 610 пользователей | ещё не рассчитано | профили, положительные взаимодействия |
| `tags.csv` | 3 683 присвоения тегов | ещё не рассчитано | дополнительный анализ после проверки |
| `links.csv` | записи для каталога `movieId` | ещё не рассчитано | необязательная связка с ID |

**Уточнение о статусе:** значения raw взяты из официального описания; локальная загрузка и очистка CSV на момент выпуска Data Card не подтверждены, поэтому числа clean сознательно не выдуманы. Сбор фотографий, внешних постеров и пользовательских событий не проводился. `synthetic=false` для данных MovieLens; резервная синтетика пока **не создана** (`synthetic=true` после генерации).

## 3. Качество и предварительная обработка

Проверить UTF-8, типы полей, пропуски, повторные пары `(userId,movieId)`, ссылки на каталог, допустимые рейтинги с шагом 0.5, `(no genres listed)`, невалидные `timestamp` и пустые теги. Оригинальные raw-файлы оставить неизменными. Для clean записать журнал исключений и контрольную сумму версии. Отсутствующую оценку **не считать негативным интересом**.

Рабочие признаки — жанры фильмов и профиль пользователя только по его историческим train-оценкам. Метки `rating` предназначены для оценки, не для формирования test-профиля. Текст тегов подключать только при доступности во времени и проверке качества/прав.

## 4. Репрезентативность

Набор содержит только пользователей с не менее чем 20 оценками; это не случайная выборка всех посетителей онлайн-кинотеатров. Разница между 610 пользователями и 9 742 фильмами создаёт разреженность оценок. В каталоге имеются фильмы разных жанров, однако **количественное распределение жанров пока не пересчитано по CSV**. Нет подтверждённого охвата новых релизов после 2018 года. Язык названий, тегов и каталогов не гарантирует пригодность русскоязычному пользователю. Данные не содержат ФИО, возраста, пола, страны, авторов плакатов, регионов и пользовательских сессий; нельзя измерить ошибки по этим сегментам. Реальные клики/сохранения в CineMatch отсутствуют.

Следствие: offline NDCG@10/HitRate@10 на этом наборе не доказывают реальный пользовательский CTR, пользу в коммерческом сервисе или качество холодного старта.

## 5. Правомерность, приватность, ограничения

Правила GroupLens разрешают исследовательское использование при атрибуции и запрещают доходное/коммерческое применение без отдельного согласования; не следует подразумевать одобрение проекта правообладателем. Условия распространения описаны в README; проектное решение — **не публиковать исходные CSV в GitHub**, чтобы исключить непреднамеренное нарушение условий при производных публикациях. Дополнительные материалы IMDb/TMDb не разрешены автоматически только потому, что в таблице имеются ID. `userId` псевдонимен, свободные теги требуют осторожного обращения.

**Основные ограничения:** временное устаревание; неравномерность выборки; субъективные рейтинги; отсутствие времени добавления фильма в каталог; недостаток независимой обратной связи; неразмеченные альтернативные фильмы не становятся автоматически отрицательными. Эти ограничения относятся к **основному результату**, а не к малозаметным примечаниям.

## 6. Разделение и версия

Предлагается хронологический per-user train/validation/test с группированием одинаковых `(userId,timestamp)`, недопуском дублирующихся `(userId,movieId)` в разные части и проверками в [split_and_plan.md](split_and_plan.md). Статистики и TF-IDF IDF считаются на обучающих наблюдениях; validation выбирает подход, test — однократно оценивает зафиксированный вариант.

**Ответственность как учебная ролевая модель:** Участник № 1 — ведение реестра и интеграция; Участник № 2 — проверки данных, split и baseline; Участник № 3 — разметка, интерпретация и пользовательские ограничения. Это распределение функций, не сведения о фактически набранной команде.

**Основание версии 1.0:** следующий пересмотр после фактической загрузки CSV и скриптового аудита; не объявлять проверку выполненной заранее.
