## 2. Проверка разрешений

README GroupLens разрешает исследовательское использование при указании первоисточника, запрещает коммерческое/доходное применение без предварительного согласования, не допускает ложного впечатления об одобрении университетом. README допускает распространение под теми же условиями, однако **для учебного GitHub-портфолио публикуются только документация и код, без CSV**. Доступность по URL сама по себе не является лицензией. Не следует смешивать права на MovieLens с разрешениями на внешние афиши, изображения или дополнительные сведения.

Рекомендуемая атрибуция: Harper, F. M.; Konstan, J. A. (2015). *The MovieLens Datasets: History and Context*. ACM TiiS 5(4). https://doi.org/10.1145/2827872

## 3. Процедура приёмки источника

1. Скачать `ml-latest-small.zip` с официального адреса локально, записать SHA-256 архива и дату фактического получения в следующую версию реестра.
2. Сопоставить фактические поля/объёмы с `schema.md`; явно оформить отличия от README.
3. Сохранить исходный архив неизменным и отдельно вести производные версии `clean`; исходные CSV не коммитить.
4. Привязать результаты расчётов к версии источника, коду и выборкам.
5. Для источников со статусом `unknown` блокировать импорт; для синтетических данных хранить отдельный контур и метку происхождения.
