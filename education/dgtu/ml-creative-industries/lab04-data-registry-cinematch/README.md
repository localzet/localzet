## Принципиальные решения

- MovieLens Latest Small используется только как учебный некоммерческий источник. Для оригинальных CSV действует лицензия GroupLens из [официального README](https://files.grouplens.org/datasets/movielens/ml-latest-small-README.html). CSV не скопированы в публичный репозиторий.
- Публикуются **документированные факты** об источнике и **планируемые** преобразования, но не вымышленные результаты очистки. RAW объёмы — по GroupLens; CLEAN пока не подсчитан на локально полученной копии.
- Для рекомендаций существующему пользователю train/validation/test разделяются хронологически по его взаимодействиям с сохранением всех одинаковых временных групп внутри одного split; валидность проверяется тестами.
- Признаки из будущего и отложенные оценки не допускаются в обучающий пользовательский профиль.
- Реальные `userId` псевдонимны, свободные теги потенциально чувствительны. Чужие постеры и внешние описания без проверенного разрешения не включаются.
- Техническая демонстрация на собственных синтетических карточках допустима только с `synthetic=true` и без претензий на качество рекомендаций на реальном рынке.
