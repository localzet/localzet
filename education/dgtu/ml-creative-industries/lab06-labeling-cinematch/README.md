## Запуск

```bash
python -m unittest -v test_prepare
# При наличии сети: сначала проверенное зеркало, затем официальный архив:
python prepare_dataset.py --output prepared
# Или после скачивания архива вручную:
python prepare_dataset.py --source /path/to/ml-latest-small.zip --output prepared
```

Требуется Python 3.11+; внешние ML-библиотеки для подготовки не нужны. Результаты выполнения сохраняются **только локально** в `prepared/` (исключено из Git), включая `clean_interactions.csv`, разбиения train/validation/test, `exclusions.csv`, `train_idf.json`, `pilot_labels.csv`, `manifest.json` с SHA-256 входных и выходных файлов. Никаких исходных MovieLens CSV с псевдонимными userId в публичном репозитории нет.

## Диагностика загрузки в Colab

В версии исправления от 08.11.2026 ноутбук показывает **полный stdout/stderr** дочернего процесса вместо одного `CalledProcessError`. Если ни один URL не доступен, он предлагает загрузить `ml-latest-small.zip` с GroupLens через окно Colab и повторно запускает подготовку с `--source`. Ошибка контрольной суммы означает другую версию файлов и не должна обходиться отключением проверки. Ноутбук следует **переоткрыть по ссылке**, поскольку старая открытая вкладка не обновляется автоматически.
