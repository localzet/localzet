# Итоги validation CineMatch baseline

Зафиксированная версия: `cinematch-popularity-baseline-v1.0.0`. Результаты вычислены по полному `ratings.csv` (Git blob SHA `51974adb19938bda0e00b2d8c051438fb33893f0`) и `movies.csv` (`2c1b2e74fe24d0fc851aa9745702fcd7777f690a`) из публичного зеркала MovieLens Latest Small. Схема группового разбиения совпадает с ЛР 6.

| Метрика | Макроусреднение | Число пользователей в знаменателе |
|---|---:|---:|
| NDCG@10 | 0.087855 | 604 |
| Recall@10 | 0.066706 | 583 |
| HitRate@10 | 0.360206 | 583 |

- Проанализировано **610** пользователей; train **62070** взаимодействий, validation **19067**. Тестовые **19699** взаимодействий не использовались при расчёте модели/метрик.
- Каталог: **9742** фильмов. Имеют хотя бы одну положительную оценку train: **4485**.
- Положительная релевантность — `rating >= 4`; градуированная релевантность 0/1/2 — как в ЛР 6.
- У **210** пользователей есть хотя бы одно совпадение с положительным validation.
- Идеальный DCG вычисляется по реально оценённым validation-позициям; **неоценённые фильмы не считаются отрицательными оценками**, хотя в офлайн-проксимерике получают нулевой gain.
- Метрики не доказывают качество в продакшене из-за разреженности и селективности оценок, а также отсутствия реального времени доступности фильмов.

**Происхождение вычислений:** агрегаты и файлы по всем пользователям рассчитаны серверным JS-анализом проверенных CSV через GitHub Blob API; Python-модуль baseline проверен локальными unit-тестами на малых примерах. Полный Python-run требуется воспроизвести по инструкции; его выполнение в текущем контейнере заблокировано сетевым доступом.
