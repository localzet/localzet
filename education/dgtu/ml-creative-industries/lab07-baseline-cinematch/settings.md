# Настройки baseline v1.0.0

| Параметр | Зафиксированное значение | Обоснование |
|---|---|---|
| Источник | MovieLens Latest Small, `ml-latest-small-2018-09-26` | Тот же набор, что в ЛР 4–6 |
| Метки | `cinematch-labels-v1.0.0` | `0 / 1 / 2`; позитивный = `2` |
| Split | групповой хронологический по `userId,timestamp` | Нет разрыва одновременных действий |
| Train | 62 070 | Только его рейтинги определяют популярность |
| Validation | 19 067 | Единственная оценочная выборка этой ЛР |
| Test | 19 699 | Не читать для обучения или оценки baseline |
| Алгоритм | число train-оценок `>= 4.0` на фильм | Минимальная модель, не персонализирована |
| Ранжирование | `(-positive_count, movieId)` | Детерминированная сортировка |
| Ранее просмотренное | исключить `userId,movieId` из train | Не рекомендовать уже оценённые пользователем фильмы |
| `k` | 10 | Единая бизнес-задача CineMatch из ЛР 1–6 |
| Каталог | все 9 742 `movieId` | Не сужать кандидатов до validation |
| Метрики | macro NDCG@10, Recall@10, HitRate@10 | Зафиксированные формулы |
| NDCG | `gain=2^rel-1`, discount `log2(rank+1)` | Градуированная релевантность 0/1/2 |
| Нет положительных val | не включать в Recall/HR denominator | Нельзя определить полноту по пустой позитивной разметке |
| `IDCG=0` | не включать в NDCG denominator | Устранить неопределённое деление |
| Неизвестные оценки | `unjudged`, gain 0 для офлайн proxy | Не трактовать как доказанное отрицание |
| Seed | не требуется (`null`) | Нет стохастических операций |
| Среда | Python >= 3.10, только stdlib | Минимум внешних зависимостей |
| Хеш конфигурации | `c92671b51534519148008188261bfd255dc0b5e975932355fcf3c2b724e39b74` | SHA-256 канонического JSON настроек |

Источник и контрольные суммы входных CSV зафиксированы в [settings.json](settings.json). При изменении `k`, шкалы релевантности или split сравнение метрик выполняется заново.
