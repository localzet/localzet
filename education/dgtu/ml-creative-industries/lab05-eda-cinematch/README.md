## Воспроизведение

1. Открыть ноутбук в Google Colab.
2. Выбрать «Среда выполнения → Выполнить все».
3. Код загружает официальные `ml-latest-small.zip` либо зеркальные CSV, сравнивает Git SHA-1 четырёх CSV с зафиксированными и анализирует строки.
4. Получить `lab05_quality_checks.csv`, `lab05_data_card_metrics.csv` и 8 PNG в `figures/`. При необходимости скачать из Colab.

Требуемые пакеты: Python 3, pandas, numpy, matplotlib, IPython (в Colab установлены по умолчанию). Сторонние изображения не скачиваются; CSV не опубликованы здесь.

## Граница достоверности

**Сохранённые графики** построены по документированному агрегированному срезу публичного зеркала MovieLens; контрольные SHA идентификаторы совпадают с доступными файлами. **Полный построчный аудит в данном окружении не был повторно запущен**, поскольку внешний источник CSV недоступен по сети. Поэтому новые результаты не заявляются как вычисленные локально: после запуска в Colab ноутбук заново произведёт их на исходном архиве. При изменении версии данных код остановится при несовпадении SHA.

При анализе неполного среза нельзя устанавливать причинность или заявлять улучшение качества ML-модели. Результаты EDA влияют на план baseline, обработку фильмов без жанров и правила временного split.
